# Changelog

## 0.0.1

- Initial release: Flutter adapters for offline_first_core.
- `SqfliteOutboxStore` — persistent outbox (FIFO autoincrement sequence).
- `ConnectivityPlusAdapter` — auto-sync trigger via connectivity_plus.
- `FlutterSecurePayloadCipher` — AES-256-GCM, per-feature keys in
  flutter_secure_storage (Keychain/Keystore).
